## 📌 Project Overview

The **Loan Portfolio Analysis** project focuses on analyzing loan, customer, branch, and payment data to understand portfolio performance and repayment trends.

Using Excel, SQL, Python, and Power BI, this project transforms raw data into meaningful insights through data cleaning, exploratory analysis, SQL queries, and interactive dashboards.

## 🎯 Project Objectives

- Analyze loan portfolio performance and distribution.
- Understand customer and branch-wise loan patterns.
- Explore payment and repayment trends.
- Clean and prepare data for analysis.
- Perform exploratory data analysis using Python.
- Create interactive dashboards using Power BI.
- Generate insights to support data-driven decisions.
